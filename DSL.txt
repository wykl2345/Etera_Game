本文档列出了Lua事件脚本中可用的全部API指令。与 Python api_bridge.py 一一对应，
所有函数签名均源自真实实现，可直接在脚本中调用。

--------------------------------------------------------------------------------
一、事件脚本规范
--------------------------------------------------------------------------------

每个 .lua 事件文件必须 return 一个 table，包含 on_event 和 execute 两个字段：

    return {
        on_event = "on_day_begin",    -- 监听的系统/游戏事件名
        priority = "high",            -- 可选：执行优先级（默认 normal）
        execute = function()          -- 事件触发时执行
            -- 你的剧本逻辑
        end
    }

priority 可选值：low / normal / high / critical（默认 normal）。
同一事件有多个剧本时按优先级降序执行，同优先级保持注册（文件名）顺序。
典型用途：早晨问候这类"每天开场"的剧本设 high，排在随机事件之前。

--------------------------------------------------------------------------------
一.5、Hub 按钮注册（可选）
--------------------------------------------------------------------------------

剧本可以声明一个 Hub（游戏主界面）入口按钮，玩家点它才触发本剧本：

    return {
        on_event = "dialogue:reimu",
        hub = {
            char = "reimu",            -- 归属角色 ID（显示在该角色卡片下）
            label = "聊聊",             -- 按钮文案
            order = 10,                -- 同角色内排序（小在前，默认 100）

            -- 【条件类：不满足就隐藏按钮】
            require_relation = 10,     -- 该角色好感 < N 时隐藏
            require_flag = "story.intro_completed",  -- "ns.key" 为假时隐藏
            hide_flag = "reimu.story_01_done",       -- 该 flag 为真时隐藏（一次性剧情）

            -- 【成本类：满足门槛但暂时做不了 → 按钮变灰并显示原因】
            stamina_cost = 20,         -- 消耗体力；不足则变灰，执行后由引擎扣除
            daily_limit = 1,           -- 每天次数上限；用完变灰，跨天自动重置
        },

    两条判定规则（重要）：
      · 条件不满足（好感/flag/角色不在本场景）→ **按钮不显示**
      · 暂时不可用（体力不足/今日次数用完）→ **按钮变灰**并给出原因

    角色按钮只在该角色与玩家**同场景**时出现（见 scenes.yaml）。
        execute = function() ... end
    }

未声明 hub 的剧本不会出现在 Hub 上（例如由 on_day_begin 自动触发的日常事件）。

推荐组织方式：一个角色的多个剧本放在 Data/scenarios/characters/<角色ID>/ 下，
每个文件一个行动/事件，方便单独修改和测试。

    characters/reimu/
      ├── dialogue.lua     on_event = "dialogue:reimu"       hub: 聊聊
      ├── training.lua     on_event = "action:reimu_training" hub: 一起修行（需好感10）
      └── morning.lua      on_event = "on_day_begin"         无 hub（自动触发）

--------------------------------------------------------------------------------
一.6、场景（Scene）
--------------------------------------------------------------------------------

场景定义在 Data/config/scenes.yaml：

    scenes:
      home:
        name: 自宅
        desc: 你在人间之里的小屋。
        adjacent: [hakurei_shrine, village]   -- 可直达的相邻场景（引擎自动补双向）
        sleep: true                          -- 可在此睡觉（恢复体力 + 推进一天）

- 玩家的当前位置就是 world.get_location()，剧本可用 world.set_location 改
- Hub 只显示**与玩家同场景**的角色（角色的 location 字段）
- Hub 的「移动」只能去相邻场景；「睡觉」只在 sleep: true 的场景可用
- 角色的初始位置在角色 YAML 的 base_location

系统预定义事件名（参考 event_bus.py EventConstants）：
    on_game_start              游戏启动时
    on_game_end                游戏结束时
    on_day_begin               每天开始
    on_day_end                 每天结束
    on_time_change             时段变化
    on_location_change         位置变化
    on_save / on_load          存档/读档
    on_scene_change            场景切换
    on_character_stat_changed  角色属性变化
    on_character_relation_changed  角色好感度变化
    on_dialogue_start / on_dialogue_end  对话开始/结束
    on_battle_start / on_battle_end      战斗开始/结束

自定义游戏事件由 event.emit() 触发，Mod之间通过事件总线解耦。


--------------------------------------------------------------------------------
二、UI 类 (ui.*) — 显示、输入、音效
--------------------------------------------------------------------------------

ui.text(text, color?, bold?)
    显示文本到日志区。
    text    : string  显示的文本内容
    color   : string? 颜色 (white/red/green/blue/yellow/cyan/pink/gray/orange/purple)
    bold    : bool?   是否加粗，默认 false
    示例：
        ui.text("你好，世界！")
        ui.text("警告！", "red", true)

ui.clear()
    清空日志区所有文本。

ui.show_image(name, position?, fade?)
    显示图片。
    name     : string  图片资源名（不含路径和扩展名）
    position : string? 位置 (left / center / right)，默认 center
    fade     : bool?   是否淡入，默认 true
    示例：
        ui.show_image("reimu_normal", "right")
        ui.show_image("background_forest")

ui.hide_image(name, fade?)
    隐藏图片。
    name : string  图片资源名
    fade : bool?   是否淡出，默认 true

ui.play_sound(name, volume?)
    播放音效。
    name   : string  音效资源名
    volume : number? 音量 0.0~1.0，默认 1.0

ui.stop_sound(name)
    停止播放指定音效。

ui.play_music(name, volume?, loop?)
    播放背景音乐。
    name   : string  音乐资源名
    volume : number? 音量 0.0~1.0，默认 0.8
    loop   : bool?   是否循环，默认 true

ui.stop_music(fade_out?)
    停止背景音乐。fade_out 默认 true（渐出）。

ui.ask_choice(options)
    显示选项菜单，等待玩家选择后返回索引。
    这是阻塞调用——会暂停脚本直到玩家点击。
    options : table  选项列表 {"选项1", "选项2", ...}
    返回   : number  玩家选择的索引（1-based）
    示例：
        local c = ui.ask_choice({"进去", "离开", "等待"})
        if c == 1 then ... end

ui.ask_input(prompt, default?, max_length?)
    显示文字输入框，等待玩家输入。
    prompt     : string  提示文字
    default    : string? 默认值，默认 ""
    max_length : number? 最大字数，默认 100
    返回       : string  玩家输入的文本

ui.set_background(name, transition?)
    切换背景图。
    name       : string  背景图片名
    transition : string? 过渡效果 (fade / slide / none)，默认 fade

ui.cg(name)
    全屏 CG 特写：盖住背景与立绘，只留 CG 与文本。
    用于好感突破、关键剧情等需要"区别于普通对话"的场合。
    name : string  CG 资源名，素材路径 resources/images/cg/{name}.png
    示例：
        ui.cg("reimu_03_confession")
        ui.text("夜里的神社，只有灯笼还亮着。", "white")
        ...
        ui.cg_off()

ui.cg_off()
    退出 CG，回到普通背景 + 立绘。

ui.show_character(char_id, expression?, position?)
    显示角色立绘。
    char_id    : string  角色ID
    expression : string? 表情名，默认 "normal"
    position   : string? 位置 (left / center / right)，默认 center
    示例：
        ui.show_character("reimu", "happy", "right")

ui.hide_character(char_id)
    隐藏角色立绘。


--------------------------------------------------------------------------------
三、数据读写类 (data.*) — 角色、属性、Flag、背包
--------------------------------------------------------------------------------

data.get_chara(id)
    获取角色数据表（只读快照）。
    返回 : table  {id, name, stats, relation, location}  或 nil
    示例：
        local r = data.get_chara("reimu")
        if r.relation >= 20 then ... end      -- 直接 .字段 访问

data.list_characters()
    返回全部已加载角色的 ID 列表。
    返回 : table  Lua table（1-based，支持 # 与 ipairs）
    示例：
        local ids = data.list_characters()
        if #ids > 0 then
            local who = ids[util.random_range(1, #ids)]   -- 随机挑一个角色
        end
    用途：避免剧本里把角色 ID 写死，新增角色后自动参与。

data.get_stat(target, stat, default?)
    获取属性值。
    target  : string  目标 ("player" 或角色ID)
    stat    : string  属性名 (hp/mp/money/stamina/exp/level/...)
    default : number? 默认值，默认 0
    返回    : number
    示例：
        local hp = data.get_stat("player", "hp")
        local mp = data.get_stat("marisa", "mp", 0)

data.set_stat(target, stat, value)
    设置属性值为绝对值。relation 自动转发到好感度方法。
    target : string  目标 ("player" 或角色ID)
    stat   : string  属性名
    value  : number  新值
    返回   : bool    是否成功
    示例：
        data.set_stat("player", "money", 100)         -- 设钱为100
        data.set_stat("player", "hp", -10)            -- 扣血10点
        data.set_stat("reimu", "relation", 50)        -- 设好感度为50（自动转发）

data.modify_stat(target, stat, delta)
    按增量修改属性，返回新值。与 modify_relation 对称。
    target : string  目标 ("player" 或角色ID)
    stat   : string  属性名（relation 会自动转发到 modify_relation）
    delta  : number  变化量（正=增加，负=减少）
    返回   : number  修改后的值
    示例：
        data.modify_stat("player", "money", -30)    -- 花钱 30（不是"设为 -30"！）
        data.modify_stat("player", "exp", 10)       -- 加经验
    注意：set_stat 是**设绝对值**，别拿它当增量用（会把原值覆盖掉）。

data.get_stage(target)
    读取角色当前关系阶段。返回阶段 key：
    hostile / distant / neutral / friendly / close / love / soulmate
    未设置过（角色还没触发突破事件）时返回空字符串 ""。
    注意：关系阶段**不随好感度自动变化**，只由突破事件用 set_stage 推进。
    返回 : string
    示例：
        if data.get_stage("reimu") == "friendly" then ... end

data.set_stage(target, stage)
    设置关系阶段 —— **关系突破事件专用**。好感度满了也只会涨数值，
    阶段必须靠事件推进（这样玩家能自由刷好感，但关系进展由剧情把关）。
    target : string  角色ID
    stage  : string  阶段 key（同上 7 档）
    返回   : bool
    示例：
        data.set_stage("reimu", "close")
        ui.text("（与灵梦的关系：亲密）", "yellow")

data.log_start(target, title)
    开始记录一次互动。之后本剧本里的 modify_relation / modify_stat /
    add_item / remove_item / buy_item / sell_item 会自动累积成一句话。
    target : string  角色ID
    title  : string  事件简略名（如 "清晨叫醒"）
    返回   : bool

data.log_commit()
    提交记录 → 角色互动历史里多一条，形如：
        [清晨叫醒 --> 好感度+5，金钱-30，获得团子×2]
    未调用 log_start 时返回 false。
    返回   : bool
    示例：
        data.log_start("reimu", "清晨叫醒")
        data.modify_relation("reimu", 5)
        data.log_commit()

data.define_stat(target, key, label, initial?)
    注册一个**自定义能力/属性**（超出 hp/mp/体力/金钱 等基础属性的部分）。
    target  : string  角色ID
    key     : string  键（如 "sword"）
    label   : string  中文显示名（如 "剑术"）
    initial : any?    初始值，默认 0；重复注册不会覆盖已有值
    返回    : bool

data.get_extra(target, key, default?)
    读自定义能力。 返回 : any
data.set_extra(target, key, value)
    写自定义能力（绝对值）。 返回 : bool
data.modify_extra(target, key, delta)
    按增量改自定义能力，返回新值（未注册时以 0 为基准）。 返回 : any
    示例：
        data.define_stat("reimu", "sword", "剑术", 0)
        data.modify_extra("reimu", "sword", 3)      -- 剑术 0 → 3

data.buy_item(item_id, price, count?)
    购买：总额 = price × count。钱不够则失败（不扣款、不给货）。
    返回 : bool   是否成功

data.sell_item(item_id, price, count?)
    出售：持有不足则失败（不移除、不加钱）。
    返回 : bool   是否成功
    示例：
        if data.buy_item("煎茶", 30) then ... end
        data.sell_item("发光蘑菇", 20, 2)          -- 卖 2 个，共 40 文

data.get_relation(target)
    获取角色好感度。
    target : string  角色ID
    返回   : number  好感度值 (-100 ~ 100)

data.set_relation(target, value)
    设置好感度为绝对值。
    target : string  角色ID
    value  : number  新值 (-100 ~ 100)
    返回   : bool    是否成功

data.modify_relation(target, delta)
    增减好感度（推荐）。
    target : string  角色ID
    delta  : number  变化量（正=增加，负=减少）
    返回   : number  修改后的好感度值
    示例：
        data.modify_relation("reimu", 5)     -- 好感+5
        data.modify_relation("marisa", -3)   -- 好感-3

data.get_flag(namespace, key, default?)
    读取全局Flag。
    namespace : string  命名空间 (story/quest/mod_xxx，core 为引擎保留)
    key       : string  Flag键
    default   : any?    不存在时的默认值
    返回      : any
    示例：
        local met = data.get_flag("coffee_mod", "met_at_cafe", false)

data.set_flag(namespace, key, value)
    写入全局Flag（不能写入 core 命名空间）。
    namespace : string  命名空间
    key       : string  Flag键
    value     : any     Flag值
    返回      : bool    是否成功
    示例：
        data.set_flag("story", "intro_done", true)

data.has_flag(namespace, key)
    检查Flag是否存在。
    返回 : bool

data.get_inventory()
    获取背包物品表 { item_id => count }。
    返回 : table

data.add_item(item_id, count?)
    添加物品到背包。
    count : number? 默认 1

data.remove_item(item_id, count?)
    从背包移除物品。
    count : number? 默认 1

data.get_item_count(item_id)
    获取物品数量。
    返回 : number

四、世界状态类 (world.*) — 时间、位置

world.get_day()
    获取当前天数（从1开始）。
    返回 : number

world.set_day(day)
    设置当前天数。day >= 1。

world.get_time()
    获取当前时段。
    返回 : string  (morning / afternoon / evening / night / dawn)

world.set_time(time)
    设置时段。time 为上述字符串之一。
    注：当前版本不自动 emit on_time_change（事件名已预留）。

world.get_location()
    获取当前位置ID。
    返回 : string

world.set_location(location)
    设置当前位置。
    注：当前版本仅更新状态并推送 status.sync，不自动 emit
    on_location_change（该事件名已预留，尚无触发点）。


--------------------------------------------------------------------------------
五、事件类 (event.*) — 事件触发与监听
--------------------------------------------------------------------------------

event.emit(event_name, payload?)
    触发自定义事件（同步：立即调用所有已注册监听者）。
    event_name : string  事件名（建议 custom:xxx 前缀）
    payload    : table?  附加数据，会装进 ctx.data 传给监听者
    示例：
        event.emit("custom:met_npc", { npc = "reimu", score = 10 })

event.listen(event_name, handler)
    运行时注册事件监听（与 event.emit 配套）。
    handler : function  接收 1 个参数：事件上下文 ctx
                         ctx.data 即 emit 时传入的 payload 表
              也允许声明为无参函数 function()，此时忽略 ctx
    示例：
        event.listen("custom:met_npc", function(ctx)
            local npc = ctx.data["npc"]
            ui.text("遇见了 " .. tostring(npc))
        end)
    注意：同一事件可注册多个 handler，按优先级/注册顺序依次调用。

event.after_days(days, callback)
    安排 N 天后执行回调。
    days     : number  延后天数
    callback : function 到期执行的回调
    注：当前版本为惰性占位（仅登记到 temp，不会真正定时触发）。


--------------------------------------------------------------------------------
六、工具类 (util.*) — 随机、日志、延时
--------------------------------------------------------------------------------

util.random()
    返回 0~1 之间的随机浮点数。
    返回 : number

util.random_range(min, max)
    返回 [min, max] 之间的随机整数。
    返回 : number

util.log(message)
    输出调试日志（不影响游戏UI）。

util.debug(message)
    输出调试日志（仅引擎 --debug 模式可见）。

util.sleep(seconds)
    暂停脚本执行指定秒数（毫秒精度）。
    注意：sleep 在 util 组，不是 ui 组！

六.5、小游戏组 (minigame)
================================================================================

minigame.start(game_id, options?)
    触发一个小游戏（阻塞：脚本挂起，等玩家游玩结束后返回结果）。
    参数:
      game_id   : string   小游戏 ID（如 "slime_battle"，注册表见 frontend/src/games/index.ts）
      options?  : table    传给小游戏的配置（可选）
    返回 : table  游戏结果（由小游戏实现决定），约定含 won 字段：
      { won = true, score = 20, ... }
    示例:
      local r = minigame.start("slime_battle", { hp = 30 })
      if r.won then
          ui.text("你击败了史莱姆！", "yellow")
          data.set_stat("player", "money", r.score)
      else
          ui.text("你被史莱姆击败了……", "red")
      end
