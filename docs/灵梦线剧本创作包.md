```text

角色剧情。先输出 3 个剧情提案（标题 / 触发条件 / 场景 / 剧情梗概 / 2-3 个选项及后果 /
是否用 CG），不要直接写代码；等我确认提案后，再输出完整 Lua 剧本。

硬性要求：
- 只使用本文列出的 Lua 指令与资源 id，不新增引擎 API。
- 不修改现有 story_01 ~ story_04 的结构、事件名、flag 名和阈值。
- 不把关系阶段写成自动升级；阶段只能由突破事件 data.set_stage 设置。
- 每个选项都要有真实后果（关系/flag/物品/属性），不做假选项。
- 文风克制、短句、少解释；灵梦不突然 OOC，不写玩家姓名/性别，不写露骨内容。
- 交付：完整 Lua 文件 + 一段 100 字以内的设计说明。
```

## 1. 世界与基调

- **世界观**：幻想乡，博丽神社 / 人间之里 / 魔法森林。日常向，不是宏大战争。
- **玩家**：一个经常来往神社的普通人；姓名、性别、过去都留白，剧本用“你”称呼。
- **基调**：安静、微苦、慢热。灵梦的懒散、穷、嘴硬是喜剧来源；孤独感和“有人陪着”的温度是暗线。
- **节奏**：一次事件只讲一个小情境；不急着告白，不连续堆情绪高潮。
- **边界**：非露骨；可以写暧昧、脸红、靠近，但不写性描写。避免黑暗猎奇和突然的生死离别。

### 灵梦的声音

- 说话短、懒、爱吐槽，常用“……”“算了”“真拿你没办法”“茶”。
- 不擅长直球表达感情；越在意越会用“无所谓”“随便”掩饰。
- 对钱、赛钱箱、扫落叶、妖怪退治有职业性的抱怨，但关键时刻可靠。
- 不要写成元气少女、撒娇女友或说教者。

**参考台词**

> “……又是你啊。最近来得挺勤的。”
> “扫了还会落，落了我还得扫。有时候真不知道图什么。”
> “那我要开始习惯有人陪了。你负责。”
> “以后这里，也是你的地方了。”

**避免**

> “人家最喜欢你了啦～”（OOC）
> “作为博丽神社的巫女，我必须守护幻想乡的和平。”（说教）
> 大段玩家内心独白 / 玩家开口说很长的话（当前剧本以第二人称叙述为主）

## 2. 当前路线总览

### 2.1 主线四段

| 顺序 | 文件 | 事件名 | Hub 按钮 | 触发条件 | 阶段 | 场景 / CG |
|---|---|---|---|---|---|---|
| 1 | `characters/reimu/story_01_friendly.lua` | `story:reimu_01` | 去神社看看（order 30） | 好感 ≥ 10 | `friendly`（友人） | 神社午后 / `reimu_01_afternoon` |
| 2 | `characters/reimu/story_02_close.lua` | `story:reimu_02` | 帮她扫落叶（order 31） | 好感 ≥ 30 且 `story_01_done` | `close`（亲密） | 神社傍晚 / `reimu_02_leaves` |
| 3 | `characters/reimu/story_03_love.lua` | `story:reimu_03` | 夜里去神社（order 32） | 好感 ≥ 60 且 `story_02_done` | `love`（恋爱） | 神社夜晚 / `reimu_03_confession` |
| 4 | `characters/reimu/story_04_soulmate.lua` | `story:reimu_04` | 一起看日出（order 33） | 好感 ≥ 80 且 `story_03_done` | `soulmate`（伴侣） | 神社黎明 / `reimu_04_sunrise` |

完成旗标：`reimu.story_01_done` ~ `reimu.story_04_done`，通过 `hide_flag` 让已完成按钮消失。

### 2.2 关系/阶段规则

- 初始好感 `0`；范围 `-100 ~ 100`。
- 阶段标签（展示用，由好感度推算）：敌视 / 疏远 / 中立 / 友人 / 亲密 / 恋爱 / 伴侣。
- **阶段不会自动升级**。只有主线突破事件调用 `data.set_stage("reimu", "friendly"|"close"|"love"|"soulmate")` 才会变。
- 好感度可以继续累积，但阶段保持不变，直到下一个突破事件。
- 关系阶段与好感度是两套东西：不要用 `set_stat`/`modify_stat` 改 `relation`，要用 `data.modify_relation`。

### 2.3 现有四段的剧情梗概

#### 1/4 神社的午后（友人）

- 灵梦坐在缘侧喝茶，刚睡醒；玩家来访。
- 关键句：“……又是你啊。最近来得挺勤的。”
- 选项与结果：
  1. “因为这里很舒服” → 好感 +8
  2. “因为想见你” → 好感 +12（灵梦把脸埋进茶碗）
  3. “路过而已” → 好感 +3
- 收尾：“……算了，坐吧。反正也没别人来。”
- 关系：`friendly`；CG 午后缘侧。

#### 2/4 扫不尽的落叶（亲密）

- 傍晚，灵梦扫落叶扫到一半发呆，说扫了还会落。
- 选项：
  1. “那就别扫了，我陪你坐着” → +12
  2. “这是你的职责吧” → +5（她有点被刺到）
  3. “我帮你扫” → +9
- 收尾：天色暗下来，“……有个人在旁边，好像确实不太一样。”
- 关系：`close`；CG 傍晚落叶。

#### 3/4 神社的台阶（恋爱）

- 夜里，灵梦坐在灯笼下的石阶上，比白天安静。
- 选项：
  1. “我有话想说” → +18
  2. “就是想见你” → +18
  3. “睡不着，随便走走” → +10（沉默地坐一会儿）
- 收尾：“……那我要开始习惯有人陪了。你负责。”
- 关系：`love`；CG 夜晚石阶。

#### 4/4 日出（伴侣）

- 天没亮被灵梦拽起来去山顶看日出，风很冷。
- 选项：
  1. “以后每天都一起看” → +15
  2. “这样就够了” → +13
  3. “……好冷” → +12（她把披肩扔给你）
- 收尾：“……以后这里，也是你的地方了。”
- 关系：`soulmate`；CG 山顶日出；首次突破给 `博丽神社的御守`。

### 2.4 日常/辅助剧本（不是主线突破）

| 文件 | 事件 | 触发 | 说明 |
|---|---|---|---|
| `characters/reimu/dialogue.lua` | `dialogue:reimu` | Hub「聊聊」，每日 3 次 | 闲聊；6 个关系阶段（cold/neutral/friendly/close/love/soulmate）× hello/chat/help/bye 话题库，当前 **90 话题 / 354 行**；同 tier 同类别尽量不连续重复；选项 +1/+3、离开；帮做事时体力 -5 |
| `characters/reimu/training.lua` | `action:reimu_training` | Hub「一起修行」，好感 ≥10 | 每日 1 次、体力 20；60% 经验 +10 好感 +2，否则 HP -10 好感 +1 |
| `characters/reimu/morning.lua` | `on_day_begin` | 第 2 天起，50% 概率 | 早晨叫醒；每天最多一个角色叫（`daily.morning_done` 占坑）；选项 +2/+1/-1 |
| `daily/coffee_shop.lua` | `on_day_begin` | 第 5 天起、好感 ≥6、未触发 | 咖啡店偶遇；进去 +5 好感、-30 钱 |
| `story/intro.lua` | `on_game_start` | 开局 | 序章；第一个选择决定初印象；选项 4 触发史莱姆小游戏 |

> 灵梦喜欢 `煎茶`、`团子`；送礼会按物品 `gift_value` 加好感，喜欢的东西额外 ×1.5。

> **日常对话库结构**：`dialogue.lua` 用 `current_tier()` 同时看好感度和**已突破 stage**，
> 高好感不会跳过主线门槛；每个 tier 分 `hello` / `chat` / `help` / `bye` 四类，
> 用 `reimu.last_daily_*` 记录上一次话题，避免连续重复。新增日常话题时沿用这个结构，
> 不要改事件名、Hub 每日次数和原有收益。

## 4. Lua 剧本契约

### 4.1 最小结构

```lua
return {
    on_event = "story:reimu_05",

    hub = {
        char = "reimu",
        label = "去神社坐坐",
        order = 34,
        require_relation = 80,
        require_flag = "reimu.story_04_done",
        hide_flag = "reimu.story_05_done",
    },

    execute = function()
        data.log_start("reimu", "场景标题")

        ui.set_background("shrine", "fade")
        ui.show_character("reimu", "normal", "center")
        ui.text("场景描写……", "white")
        ui.text("灵梦：……", "pink")

        local c = ui.ask_choice({ "选项一", "选项二", "选项三" })
        if c == 1 then
            ui.text("结果一。", "white")
            data.modify_relation("reimu", 5)
        elseif c == 2 then
            ui.text("结果二。", "white")
            data.modify_relation("reimu", 2)
        else
            ui.text("结果三。", "white")
            data.modify_relation("reimu", 1)
        end

        data.set_flag("reimu", "story_05_done", true)
        data.log_commit()
    end
}
```

### 4.2 Hub 字段

| 字段 | 作用 |
|---|---|
| `char` | 归属角色 id（`reimu`） |
| `label` | 按钮文字 |
| `order` | 排序（越小越靠前） |
| `require_relation` | 好感不足 → **按钮隐藏** |
| `require_flag` | 前置 flag 不满足 → **隐藏** |
| `hide_flag` | 该 flag 为真 → **隐藏**（用于已完成） |
| `stamina_cost` | 体力不足 → 按钮置灰 |
| `daily_limit` | 当天次数用完 → 置灰 |

### 4.3 常用指令（只列写作会用到的）

**UI**

```lua
ui.text("文本", "pink")                  -- 颜色：white/red/green/blue/yellow/pink/gray/cyan/orange/purple
ui.text("加粗", "yellow", true)
ui.set_background("shrine", "fade")      -- shrine/home/forest/market
ui.show_character("reimu", "normal", "center")  -- 表情：normal/happy/serious
ui.hide_character("reimu")
ui.cg("reimu_05_xxx")                    -- 新 CG 需要先有素材；没有素材会显示占位标记
ui.cg_off()
local c = ui.ask_choice({ "A", "B" })    -- 返回 1-based 下标，阻塞
```

**数据**

```lua
data.get_relation("reimu")
data.modify_relation("reimu", 5)          -- 增量；不要用 set_stat 改 relation
data.modify_stat("player", "stamina", -5) -- 增量；set_stat 是设绝对值
data.set_stage("reimu", "close")           -- 只给突破事件用
data.set_flag("reimu", "story_05_done", true)
data.get_flag("reimu", "story_05_done", false)
data.has_flag("reimu", "story_05_done")
data.add_item("煎茶", 1)
data.log_start("reimu", "标题")
data.log_commit()                          -- 记录到角色互动历史
```

**世界 / 工具**

```lua
world.get_day()
world.get_time()                          -- morning/afternoon/evening/night/dawn
world.set_time("evening")
util.random()                             -- 0~1
util.random_range(1, 10)
util.sleep(0.5)                           -- 只用于演出停顿；不要靠它“等玩家读完”
util.log("调试信息")
```

### 4.4 视觉资源 id

- 背景：`shrine` / `home` / `forest` / `market`
- 灵梦立绘：`normal` / `happy` / `serious`
- 魔理沙立绘：`normal` / `grin` / `happy`
- 现有 CG：
  - `reimu_01_afternoon`
  - `reimu_02_leaves`
  - `reimu_03_confession`
  - `reimu_04_sunrise`
  - 备用：`reimu_unkown_evening_meeting_with_map`（男主×灵梦夜谈，暂未接入，可建议使用）
- 新 CG 命名：`reimu_05_<主题>` / `reimu_06_<主题>`；没有素材也能写，但游戏里只显示占位标记。

### 4.5 文本/视觉时序（重要）

引擎现在会把 `ui.hide_character` / `ui.cg_off` 等清理指令**延迟到玩家点击确认之后**执行，
所以：

- 结尾按常规写 `cg_off()` / `hide_character()` 即可，**不需要**为了“让立绘多留一会儿”加 `util.sleep`。
- 中间的表情切换（`ui.show_character("reimu","happy",...)`）会等当前文本读完再切，不会抢跑。
- `util.sleep` 只用于场景停顿/演出节奏，不要拿来做时序控制。

### 4.6 常见错误

- ❌ `data.set_stat("player", "money", -30)`：这是**设成** -30，不是扣 30；用 `modify_stat`。
- ❌ `data.set_stat("reimu", "relation", 5)`：会覆写好感；用 `modify_relation`。
- ❌ 用 `data.set_stage` 做日常小场景：阶段只属于突破事件。
- ❌ 选项没有后果 / 三个选项结果一样：写作 AI 最容易犯的错。
- ❌ 一上来就写很深的情感：当前 0-10 好感阶段，灵梦对你只是“眼熟”。
- ❌ 写玩家姓名、性别、前世、宏大设定：会与现有留白冲突。

## 5. 写作规范

### 5.1 篇幅与节奏

- 单个事件：10~20 条 `ui.text`，2~3 个选项；场景不超过一个地点/一个时段。
- 每条文本 1~2 句；一段只表达一个意思，便于逐字打印和手机阅读。
- 选项之间要有明确语气差异：亲近 / 试探 / 退开 / 玩笑 / 务实。
- 一次事件只推进一小步关系；主线突破才允许 +8~18，日常场景 +1~5。
- 不要在同一个事件里连续两次“关系突破”。

### 5.2 选项后果

- 每个选项至少改变一项：`modify_relation` / `set_flag` / `add_item` / `modify_stat`。
- 好感差建议 2~6；主线突破选项差 3~9。
- 负面选项也要写得不讨厌：灵梦会吐槽，但不会突然翻脸。
- 可以用 flag 埋后续伏笔（如 `reimu.festival_invited`），但要在后续事件里真的用到。

### 5.3 场景与连续性

- 神社白天=shrine，傍晚/夜晚也可复用 shrine + `world.set_time`；自宅=home；森林=forest；市集=market。
- 主线 1 午后、2 傍晚、3 夜晚、4 黎明；新场景注意时间连续性。
- CG 只在关键情绪点用；普通闲聊不要每段都 CG。
- 灵梦的穿着/发饰/性格保持 canon：红白巫女服、大红蝴蝶结、懒散但可靠。

### 5.4 推荐扩写位置

| 位置 | 建议内容 | 触发/条件 |
|---|---|---|
| 1→2 之间（好感 10~29） | 日常小事件：一起喝茶、赛钱箱、扫落叶前传 | 已完成 01，未完成 02 |
| 2→3 之间（好感 30~59） | 灵梦的过去、神社的冷清、第一次被依赖 | 已完成 02，未完成 03 |
| 3→4 之间（好感 60~79） | 约会/庙会/雨夜、确认关系后的不安 | 已完成 03，未完成 04 |
| 4 之后（soulmate） | 伴侣日常、季节事件、见家长式的妖怪朋友 | `story_04_done` |
| 任意阶段 | 魔理沙插科打诨、咖啡店、修行变体 | 用 `daily_limit`/flag 控制 |

> 不要新增 `stage` 值（如 `married`）；当前 UI 只认识已有阶段。需要新阶段时先和引擎侧确认。

## 附录 A：完整样例（story_01，现有实现）

```lua
-- 灵梦主线 1/4：神社的午后（好感 10 → 阶段「友人」）
-- 突破条件：好感 ≥ 10；完成后按钮隐藏（hide_flag）
-- 关系突破必须走事件：好感度满了也不会自动升阶

return {
    on_event = "story:reimu_01",

    hub = {
        char = "reimu",
        label = "去神社看看",
        order = 30,
        require_relation = 10,
        hide_flag = "reimu.story_01_done",
```
