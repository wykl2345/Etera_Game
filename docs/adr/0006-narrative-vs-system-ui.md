# ADR-0006: 叙事界面平移 + 系统界面 Web 重设计

界面分两类对待：叙事界面（立绘/背景/文本流/选项）延续 v1 的 galgame 布局，Web 化时平移复用（差异小）；系统界面（主菜单/设置/存档/角色详情等）从 v1 的 Qt 桌面风格**重新设计**为浏览器原生交互（弹窗/侧栏/路由）。原因是重构动机之一就是"节约 UI 开发成本 + 现代化"，系统界面是玩家第一印象，最该摆脱 Qt 终端风格。

**Consequences**: 主菜单（Phase 2）即采用现代化 Web 风格（CSS 渐变 + 卡片式选项），作为 Phase 3 所有系统界面的设计基准；v1 终端风仅保留在叙事文本流中。
