# ADR-0007: 美术生产改用 ChatGPT Plus + 提示词包

本地 ComfyUI（RTX 3050 Ti Laptop，4GB 显存）只能稳定输出 `624×912` 立绘与 `768×432` 背景/CG，
人物一致性靠固定 seed + 提示词前缀仍会漂移，CG 构图也常崩；这批图只适合做占位，不足以作为正式素材。

改为 **ChatGPT Plus 出图**：项目维护可粘贴的提示词包（`docs/美术提示词.md`），由开发者生成、
人工挑图，再用 rembg + ImageMagick 做抠图/裁剪/缩放并按规范落盘。角色一致性以**角色设定图作为参考附件**
来约束，而不是 seed。本地 ComfyUI 脚本（`tools/comfyui_generate.py`、`tools/process_assets.py`）归档保留，
不删除、不再作为主流程。

**Consequences**:

- 美术产出的质量与一致性从「模型/显存限制」转为「提示词 + 参考图 + 人工筛选」，项目侧只维护提示词资产。
- 出图是人工环节，不进入自动化测试；引擎仍按资源 id 加载，缺图时显示占位，不影响开发与联调。
- 资源 id、目录结构、目标尺寸不变（`docs/美术资源规范.md` v3），剧本与存档无需迁移。
- 后续如需批量/可复现，可再评估本地放大、抠图与提示词版本化管理，但不阻塞当前内容创作。
