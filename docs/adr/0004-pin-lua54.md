# ADR-0004: 固定 lupa.lua54

lupa 的二进制 wheel 内置 Lua 5.1-5.5 + LuaJIT，默认 `import lupa` 会随 lupa 升级漂移 Lua 版本（当前默认到 5.5）。Mod 沙箱固定 `import lupa.lua54`，使 Lua 运行时版本与 Mod 参考手册（lua.org/manual/5.4）永久对应。备选（跟随默认版本）被否决：Lua 5.5 手册与生态尚不普及，且版本漂移会让 Mod 行为不可复现。

**Consequences**: 所有后端文件统一 `import lupa.lua54`；升级 lupa 时需验证 5.4 绑定仍可用。
