## 一、目录结构与命名

资源全部放在 `resources/images/` 下，**文件名 = 引擎里的资源 id**，不带扩展名的部分直接用：

```
resources/images/
├── characters/                    # 角色立绘（透明背景）
│   ├── reimu/
│   │   ├── normal.png
│   │   ├── happy.png
│   │   └── serious.png
│   └── marisa/
│       ├── normal.png
│       ├── grin.png
│       └── happy.png
│
├── avatars/                       # 角色头像（透明背景，方形）
│   ├── reimu/{normal,happy,...}.png
│   └── marisa/{normal,grin,...}.png
│
├── backgrounds/                   # 场景背景（不透明）
│   ├── shrine.png                 # 博丽神社
│   ├── home.png                   # 自宅
│   ├── forest.png                 # 魔法森林
│   └── market.png                 # 人间之里市集（待补）
│
├── cg/                            # 全屏 CG 特写（不透明）
│   ├── reimu_01_afternoon.png
│   ├── reimu_02_leaves.png
│   ├── reimu_03_confession.png
│   └── reimu_04_sunrise.png
│
└── ui/                            # UI 装饰元素
    ├── heart.png                  # 好感度图标
    └── frame_char.png             # 立绘边框（可选）
```

**命名规则**

| 类型 | 规则 | 示例 |
|---|---|---|
| 立绘 / 头像 | `{角色ID}/{表情}.png` | `reimu/happy.png` |
| 背景 | `{场景ID}.png`，与 `scenes.yaml` 的 scene id 一致 | `shrine.png` |
| CG | `{角色ID}_{序号}_{主题}.png` | `reimu_03_confession.png` |

> 引擎按 id 直接拼路径，**改文件名等于改剧本**，不要随意重命名。

## 二、立绘 (Sprite)

### 2.1 规格

| 项 | 值 |
|---|---|
| **目标尺寸** | `1200 × 1800`（2:3，高清屏友好） |
| 兼容尺寸 | `600 × 900`（标准，引擎会等比缩放） |
| 格式 | PNG **RGBA**（背景必须透明） |
| 色彩空间 | sRGB |
| 边缘 | 底部渐隐 60~80px，左右羽化 20px（alpha 渐变到 0） |

### 2.2 构图

- **半身到全身**，脚底贴近画面底部；头顶留 5% 空白
- 角色居中，左右各留约 10% 透明边距
- 视线朝**正前方或略微朝画面中心**（对话时看向文本方向）
- 不做硬切边，轮廓自然透明

### 2.3 表情清单（当前需要）

| 角色 | 表情文件 | 中文 | 使用场景 |
|---|---|---|---|
| reimu | `normal.png` | 通常 | 默认、日常对话 |
| reimu | `happy.png` | 喜 | 好感提升、日出事件 |
| reimu | `serious.png` | 认真 | 修行、退魔 |
| marisa | `normal.png` | 通常 | 默认 |
| marisa | `grin.png` | 得意 | 恶作剧、炫耀 |
| marisa | `happy.png` | 喜 | 收到喜欢的东西 |

### 2.4 可扩展表情（按需追加，不必一次做完）

`angry`（怒）· `sad`（哀）· `surprised`（惊）· `embarrassed`（羞）·
`thinking`（思）· `smirk`（坏笑）· `blush`（脸红）· `sleep`（睡）

新增表情只需把 `{表情}.png` 放进角色目录，剧本里 `ui.show_character("reimu","angry")` 即可用；
缺图时引擎显示占位卡片。

## 三、头像 (Avatar)

| 项 | 值 |
|---|---|
| **目标尺寸** | `512 × 512`（引擎缩放到 256 显示） |
| 最小 | `256 × 256` |
| 格式 | PNG **RGBA** |

- 肩以上面部特写，**面部占画面 60% 以上**，眼睛约在上下 1/3 处
- 四周留 8px 透明安全区
- 表情文件名与立绘一致（同名可在两处复用）

> 当前 UI 用立绘缩略图占位，头像尚未接入；先按此规格备着。

## 四、背景 (Background)

| 项 | 值 |
|---|---|
| **目标尺寸** | `1920 × 1080`（16:9） |
| 兼容尺寸 | `1280 × 720` |
| 格式 | PNG（不透明）或 JPG（质量 ≥ 90） |

- 画面**下方 35~45% 会被文本区遮挡**，重要信息放上半部分
- 不需要角色，纯场景
- 同一场景的日夜差异可另存 `{scene}_night.png`（剧本用 `ui.set_background("shrine_night")`）

### 4.1 当前需要的背景

| 文件 | 场景 | 描述要点 |
|---|---|---|
| `shrine.png` | 博丽神社 | 山顶神社、石阶、赛钱箱、晴天，稍显冷清 |
| `home.png` | 自宅 | 室内、和式小屋、被褥、木窗 |
| `forest.png` | 魔法森林 | 雾气、巨大蘑菇、斑驳光线 |
| `market.png` | 人间之里市集 | 摊位、灯笼、人群（待补） |

## 五、CG 特写

用于好感突破等关键剧情（`ui.cg("名字")`），**全屏、无立绘**。

| 项 | 值 |
|---|---|
| **目标尺寸** | `1920 × 1080`（16:9） |
| 格式 | PNG / JPG |
| 构图 | 有角色，但不必是标准立绘比例；横向构图为主 |

### 5.1 当前需要的 CG

| 文件 | 触发剧情 | 描述要点 |
|---|---|---|
| `reimu_01_afternoon.png` | 神社的午后（好感 10） | 灵梦在缘侧喝茶，午后阳光，放松 |
| `reimu_02_leaves.png` | 扫不尽的落叶（好感 30） | 傍晚，落叶满地的神社，灵梦拿着扫帚发呆 |

## 六、分辨率总表（含小显存生成方案）

GPU 显存有限时按「小图生成 → 放大」两步走，**不要直接生成目标大图**。

| 资源 | 目标尺寸 | 生成尺寸（SD1.5） | 生成尺寸（SDXL） | 放大倍数 |
|---|---|---|---|---|
| 立绘 | 1200×1800 | **512×768** | 832×1216 | ×2 ~ ×2.5 |
| 头像 | 512×512 | **512×512** | 768×768 | ×1（够用） |
| 背景 | 1920×1080 | **768×432** | 1024×576 | ×2.5 |
| CG | 1920×1080 | **768×432** | 1024×576 | ×2.5 |

**要点**

- SD1.5 对极宽/极窄比例容易崩，16:9 用 `768×432` 而非 `1920×1080` 直出
- 放大用二次采样（如 `4x-UltraSharp` / `RealESRGAN`）时，**先 2x 再按需缩到目标**，比一步 4x 更稳
- 立绘底色是透明，放大后需要重新抠图（建议生成时就带纯色/透明背景提示词，如 `white background, simple background`）
- 显存 < 6GB 时：SD1.5 + `--lowvram`，关闭 refiner、batch size 固定 1

## 七、风格一致性

- **色调**：整体偏冷、低饱和（引擎 UI 是暗色 `#0C0C0C` 底），避免高饱和纯色块
- **画风**：日式动画风（anime style），线条干净，不要写实照片感
- **角色一致性**：同一角色的不同表情建议用**同一 seed + 相同提示词前缀**生成，只改表情关键词
- 提示词建议统一追加负面：`lowres, bad hands, extra fingers, watermark, text, signature`

## 八、与 v1 规范的差异

| 项 | v1 | v2 |
|---|---|---|
| 立绘路径 | `characters/{id}/{expr}.png` | 相同 |
| 立绘尺寸 | 600×900 / 500×1000 | **1200×1800 为主**（600×900 兼容） |
| 背景命名 | `hakurei_shrine_day.png` 等长名 | **`{scene_id}.png`**（与 scenes.yaml 一致，如 `shrine.png`） |
| CG | 无（用背景临时替代） | **独立 `cg/` 目录 + `ui.cg()` 指令** |
| 头像 | 256×256 标准 | 512×512 为主（缩放到 256 显示） |
| 表情清单 | 统一 7 种 | 按**当前剧本实际用到**列出，其余按需追加 |
