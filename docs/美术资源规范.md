> 更新: 2026-11-03 | 适用引擎版本: 2.2.0
> 取代 v2 规范（本地 ComfyUI 出图），差异见文末。

## 一、目录结构与命名

资源全部放在 `resources/images/` 下，**文件名 = 引擎里的资源 id**，不带扩展名的部分直接用：

```
resources/images/
├── characters/                    # 角色立绘（透明背景）
│   ├── reimu/
│   │   ├── normal.png
│   │   ├── happy.png
│   │   └── serious.png
│   └── marisa/
│       ├── normal.png
│       ├── grin.png
│       └── happy.png
│
├── avatars/                       # 角色头像（透明背景，方形）
│   ├── reimu/{normal,happy,...}.png
│   └── marisa/{normal,grin,...}.png
│
├── backgrounds/                   # 场景背景（不透明）
│   ├── shrine.png                 # 博丽神社
│   ├── home.png                   # 自宅
│   ├── forest.png                 # 魔法森林
│   └── market.png                 # 人间之里市集（待补）
│
├── cg/                            # 全屏 CG 特写（不透明）
│   ├── reimu_01_afternoon.png
│   ├── reimu_02_leaves.png
│   ├── reimu_03_confession.png
│   └── reimu_04_sunrise.png
│
└── ui/                            # UI 装饰元素
    ├── heart.png                  # 好感度图标
    └── frame_char.png             # 立绘边框（可选）
```

**命名规则**

| 类型 | 规则 | 示例 |
|---|---|---|
| 立绘 / 头像 | `{角色ID}/{表情}.png` | `reimu/happy.png` |
| 背景 | `{场景ID}.png`，与 `scenes.yaml` 的 scene id 一致 | `shrine.png` |
| CG | `{角色ID}_{序号}_{主题}.png` | `reimu_03_confession.png` |

> 引擎按 id 直接拼路径，**改文件名等于改剧本**，不要随意重命名。

## 二、立绘 (Sprite)

### 2.1 规格

| 项 | 值 |
|---|---|
| **目标尺寸** | `1200 × 1800`（2:3，高清屏友好） |
| ChatGPT 输出 | `1024 × 1536`（2:3）→ 抠图后放大到目标尺寸 |
| 兼容尺寸 | `600 × 900`（标准，引擎会等比缩放） |
| 格式 | PNG **RGBA**（背景必须透明） |
| 色彩空间 | sRGB |
| 边缘 | 底部渐隐 60~80px，左右羽化 20px（alpha 渐变到 0） |

### 2.2 构图

- **半身到全身**，脚底贴近画面底部；头顶留 3~5% 空白
- 角色居中，左右各留约 10% 透明边距
- 视线朝**正前方或略微朝画面中心**（对话时看向文本方向）
- 不做硬切边，轮廓自然透明

### 2.3 表情清单（当前需要）

| 角色 | 表情文件 | 中文 | 使用场景 |
|---|---|---|---|
| reimu | `normal.png` | 通常 | 默认、日常对话 |
| reimu | `happy.png` | 喜 | 好感提升、日出事件 |
| reimu | `serious.png` | 认真 | 修行、退魔 |
| marisa | `normal.png` | 通常 | 默认 |
| marisa | `grin.png` | 得意 | 恶作剧、炫耀 |
| marisa | `happy.png` | 喜 | 收到喜欢的东西 |

### 2.4 可扩展表情（按需追加，不必一次做完）

`angry`（怒）· `sad`（哀）· `surprised`（惊）· `embarrassed`（羞）·
`thinking`（思）· `smirk`（坏笑）· `blush`（脸红）· `sleep`（睡）

新增表情只需把 `{表情}.png` 放进角色目录，剧本里 `ui.show_character("reimu","angry")` 即可用；
缺图时引擎显示占位卡片。

## 三、头像 (Avatar)

| 项 | 值 |
|---|---|
| **目标尺寸** | `512 × 512`（引擎缩放到 256 显示） |
| ChatGPT 输出 | `1024 × 1024` → 抠图后缩到目标尺寸 |
| 最小 | `256 × 256` |
| 格式 | PNG **RGBA** |

- 肩以上面部特写，**面部占画面 60% 以上**，眼睛约在上下 1/3 处
- 四周留 8px 透明安全区
- 表情文件名与立绘一致（同名可在两处复用）

> 当前 UI 用立绘缩略图占位，头像尚未接入；先按此规格备着。

## 四、背景 (Background)

| 项 | 值 |
|---|---|
| **目标尺寸** | `1920 × 1080`（16:9） |
| ChatGPT 输出 | `1536 × 1024`（3:2）→ 裁 16:9 → 放大 |
| 兼容尺寸 | `1280 × 720` |
| 格式 | PNG（不透明）或 JPG（质量 ≥ 90） |

- 画面**下方 35~45% 会被文本区遮挡**，重要信息放上半部分
- 不需要角色，纯场景
- 同一场景的日夜差异可另存 `{scene}_night.png`（剧本用 `ui.set_background("shrine_night")`）

### 4.1 当前需要的背景

| 文件 | 场景 | 描述要点 |
|---|---|---|
| `shrine.png` | 博丽神社 | 山顶神社、石阶、赛钱箱、晴天，稍显冷清 |
| `home.png` | 自宅 | 室内、和式小屋、被褥、木窗 |
| `forest.png` | 魔法森林 | 雾气、巨大蘑菇、斑驳光线 |
| `market.png` | 人间之里市集 | 摊位、灯笼、人群（待补） |

## 五、CG 特写

用于好感突破等关键剧情（`ui.cg("名字")`），**全屏、无立绘**。

| ChatGPT 输出 | `1536 × 1024`（3:2）→ 裁 16:9 → 放大 |
| 格式 | PNG / JPG |
| 构图 | 有角色，但不必是标准立绘比例；横向构图为主 |

## 六、出图流程（ChatGPT Plus）

> 2026-11 起本地 ComfyUI 停用：4GB 显存只能稳定出 `624×912` 立绘 / `768×432` 背景，人物一致性靠 seed
> 不可控，质量不达正式素材标准。改用 ChatGPT Plus 出图，项目只维护**提示词包**。
> 决策记录：`docs/adr/0007-chatgpt-art-pipeline.md`；提示词：`docs/美术提示词.md`。

### 6.1 一次出图

1. 新建对话（**一张图一个对话**），上传该角色的定稿设定图作为参考。
2. 从 `docs/美术提示词.md` 复制对应提示词，替换方括号内容。
3. 明确比例：立绘/头像 2:3 竖版或 1:1；背景/CG 3:2 横版。
4. 不满意时做**增量修改**，不要整段重写；同一角色只改表情关键词。
5. 下载原图 → 抠图/裁剪/缩放 → 按第一节命名放入 `resources/images/`。
6. 在提示词文档的「生成记录」里登记最终提示词，方便复现。
7. 生成进度、上传验收与归档统一走 `docs/美术素材待办.md`，验收通过后覆盖旧占位。

### 6.2 尺寸与后处理

| 资源 | ChatGPT 请求 | 后处理 | 目标 |
|---|---|---|---|
| 立绘 | `1024×1536`（2:3） | rembg 抠图 → 等比放大 | `1200×1800` RGBA |
| 头像 | `1024×1024`（1:1） | 抠图 → 缩小 | `512×512` RGBA |
| 背景 | `1536×1024`（3:2） | 裁 16:9 → 放大 | `1920×1080` |
| CG | `1536×1024`（3:2） | 裁 16:9 → 放大 | `1920×1080` |

> 比例不对就重新生成，**不要拉伸**。背景/CG 裁剪保留上半部——下缘本来就会被文本框遮住。

### 6.3 抠图与缩放

立绘推荐用 `tools/process_sprite.py` 一步完成（自动判断是否去背、清 alpha 噪点、缩放到 1200×1800）；
背景/CG 用 `tools/process_scene.py`（裁 16:9 → 1920×1080，不去背）。下面是等价的手工命令。

```bash
# 立绘/头像去背（生成时已是纯灰底）
rembg i raw.png cutout.png

# 立绘：1024×1536 → 1200×1800（保持 2:3）
magick cutout.png -resize 1200x1800! -background none -gravity center \
  -extent 1200x1800 resources/images/characters/reimu/normal.png

# 头像：1024×1024 → 512×512
magick cutout.png -resize 512x512! resources/images/avatars/reimu/normal.png

# 背景/CG：1536×1024 → 16:9（保留上半部）→ 1920×1080
magick raw.png -resize 1920x1080^ -gravity north -extent 1920x1080 \
  resources/images/backgrounds/shrine.png
```

### 6.4 落盘自检

- `file` 显示立绘/头像为 RGBA，尺寸精确
- 全身完整、脚没被裁、没有文字/水印
- 下缘 35~45% 没有重要信息
- 游戏里实际跑一遍对应剧本，确认构图与文本不打架

## 七、风格一致性

- **色调**：整体偏冷、低饱和（引擎 UI 是暗色 `#0C0C0C` 底），避免高饱和纯色块
- **画风**：日式动画风（anime style / cel-shaded），线条干净，不要写实照片感或 3D 渲染感
- **角色一致性**：ChatGPT 没有 seed，以**角色设定图**为锚点——每张图上传参考图并写
  `Keep face, hairstyle, outfit and art style identical`，一次只改一个变量（表情/姿势）
- **背景一致性**：同一地点复用同一张底图；需要时段变体时从原图改光，不要重新描述整个场景
- **提示词总纲与负面词**统一放在 `docs/美术提示词.md` 第二节，各图不要自创一套

## 八、版本差异

| 项 | v2 | v3（当前） |
|---|---|---|
| 出图方式 | 本地 ComfyUI（SDXL / SD1.5） | **ChatGPT Plus** |
| 立绘生成 | 832×1216 / 624×912 | **1024×1536 → 1200×1800** |
| 背景/CG 生成 | 768×432 / 1024×576 | **1536×1024 → 1920×1080** |
| 一致性手段 | 同 seed + 相同提示词前缀 | **角色设定图参考 + 固定外观描述** |
| 依赖工具 | `comfyui_generate.py` / `process_assets.py` | 提示词包 + rembg + ImageMagick |
| 规范文档 | 美术资源规范 v2 | 本文 + `docs/美术提示词.md` |

> v1 → v2 的路径/命名决策继续有效：立绘 `characters/{id}/{expr}.png`、背景 `{scene_id}.png`、
> CG 独立 `cg/` 目录。v3 只改生产工具，不改资源 id，剧本无需迁移。
