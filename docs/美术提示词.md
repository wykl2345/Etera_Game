## 一、使用流程

1. **一张图一个对话**。新建对话再生成，避免上一张的构图/颜色污染下一张。
2. **先做角色设定图**（见第四节）。之后每次生成该角色，都把设定图作为附件上传，并要求「保持脸、发型、服装、画风完全一致」。
3. **从本文复制完整提示词**。方括号 `[...]` 里的内容按需替换，其余不要删——风格与构图约束都在里面。
4. **明确尺寸**。ChatGPT 默认可能给正方形；提示词里已写 `2:3 portrait` / `3:2 landscape`，如果它仍给错，直接回一句：
   > Regenerate at exactly 2:3 portrait (1024×1536), full body from head to feet.
5. **不满意时做增量修改**，不要整段重写：
   > Keep everything identical, but make the expression calmer and the lighting softer.
6. **下载原图 → 后处理 → 按命名落盘**（见第三节与 `docs/美术资源规范.md`）。
7. **记录最终提示词**。填到文末「生成记录」，方便复现和换人重画。

> 版权提示：本项目是非商业东方同人。ChatGPT 对「东方 Project / 博丽灵梦 / 雾雨魔理沙」这类具名角色可能拒答或画偏。
> 本文提示词已改为**只描述外观、不写角色名**；若你仍想加名字，把名字加在 `Character:` 段开头即可，但要做好被拒的准备。

## 二、全局风格与负面词

所有提示词末尾都已内嵌下面两段；单独生成时也请带上。

**风格（Style）**

```text
Rendered in a high-quality Japanese visual novel style: clean cel-shaded anime illustration,
crisp and confident line art, soft diffused natural light, muted slightly desaturated colors,
subtle film grain, cinematic depth, highly detailed.
No text, no letters, no watermark, no signature, no logo, no UI elements, no frame.
```

**避免（Avoid）**

```text
Avoid: low resolution, blurry, bad anatomy, deformed hands, extra fingers, missing fingers,
asymmetric eyes, cross-eyed, text, watermark, signature, logo, oversaturated colors,
harsh flash lighting, 3D render, photorealistic, chibi proportions, cropped feet,
duplicated limbs, messy line art.
```

**项目色调**：整体偏冷、低饱和，和引擎暗色 UI（`#0C0C0C` 底）协调；只有灯笼/夕阳/朝阳等光源处允许暖色，且不要荧光饱和。

## 三、尺寸、裁剪与抠图

ChatGPT Plus 常用输出：`1024×1024`（方）、`1536×1024`（3:2 横）、`1024×1536`（2:3 竖）。

| 资源 | ChatGPT 请求 | 后处理 | 项目目标 |
|---|---|---|---|
| 立绘 | 1024×1536（2:3 竖） | 抠图 → 等比放大 | **1200×1800 RGBA** |
| 头像 | 1024×1024（1:1） | 抠图 → 缩小 | **512×512 RGBA** |
| 背景 | 1536×1024（3:2 横） | 裁 16:9 → 放大 | **1920×1080** |
| CG | 1536×1024（3:2 横） | 裁 16:9 → 放大 | **1920×1080** |

> 不要用拉伸把 1:1 拉成 2:3。比例不对就重新生成，拉伸会毁脸和身材比例。

**抠图**（立绘/头像必须是透明底）：

```bash
# 任选其一
rembg i raw.png cutout.png
# remove.bg / Photoshop「选择主体」也可以
```

提示词里统一要求 `flat uniform neutral gray background (#9A9A9A)`，比纯白更好抠（白衣不会和背景糊在一起），也不容易留绿边。

**缩放/裁剪**（ImageMagick 7）：

```bash
# 立绘：1024×1536 → 1200×1800
magick cutout.png -resize 1200x1800! -background none -gravity center \
  -extent 1200x1800 resources/images/characters/reimu/normal.png

# 头像：1024×1024 → 512×512
magick cutout.png -resize 512x512! resources/images/avatars/reimu/normal.png

# 背景 / CG：1536×1024 → 16:9（保留上半部，裁掉会被文本框遮住的下缘）
magick raw.png -resize 1920x1080^ -gravity north -extent 1920x1080 \
  resources/images/backgrounds/shrine.png
```

**检查**：

```bash
file resources/images/characters/reimu/normal.png   # 应为 RGBA
magick identify -format "%wx%h %[channels]\n" resources/images/characters/reimu/normal.png
```

## 十、一致性工作流

ChatGPT 没有 seed，靠这四步把漂移压到最小：

1. **定妆**：先出角色设定图（第四节），只保留一张你认为「就是她」的正面全身图。
2. **锁定参考**：每张立绘/头像都上传这张正面全身图，并在提示词开头写
   `Use the attached character reference sheet as the exact character reference.`
3. **一次只改一个变量**：换表情就只改 `Expression:`；换姿势就只改 `Pose:`。不要同时换服装和构图。
4. **拒绝漂移**：如果脸型、发饰、服装细节变了，直接回
   > Keep everything identical to the attached reference; only change the expression. The face shape, hair, bow and outfit must match exactly.
   连续两次仍漂移，就重新上传参考图重开一个对话。

**跨角色同框**（CG 4 的日出）：先分别定稿两个角色的立绘，再在同一条对话里上传两张参考图，要求「same two characters, back view」。背影比正脸容易保持，但仍要检查身高差和发色。

**背景一致性**：同一地点复用同一张底图；需要时段变体时，从原图改光，而不是重新描述整个场景（见 7.5）。

## 十二、常见问题

| 现象 | 处理 |
|---|---|
| 输出是正方形 | 回一句 `Regenerate at exactly 2:3 portrait (1024×1536), full body from head to feet.` |
| 脚被裁 / 画面太满 | 加强 `full body visible, feet near the bottom edge, nothing cropped, 3% margin above the head` |
| 白衣和背景糊在一起 | 背景改 `#9A9A9A` 中灰；抠图后用 1px 描边检查边缘 |
| 出现文字/签名 | 结尾再强调 `No text, no letters, no signature, no watermark`，仍出现就重生成 |
| 角色被画成别人 | 上传设定图 + 固定外观描述；删掉提示词里可能冲突的形容词 |
| 拒绝生成（版权） | 去掉角色名，只保留外观描述（本文已是这种写法） |
| 画风偏 3D/写实 | 加强 `cel-shaded anime illustration, flat colors, clean line art`，并加 `Avoid: 3D render, photorealistic` |
| 手崩 | 提示词加 `hands behind her back` / `hands in pockets` / `holding a teacup with both hands`，用道具遮手 |
| 太亮/太饱和 | 加 `muted colors, low saturation, soft natural light, film-like` |
| 背景和立绘风格不搭 | 背景也带同一段 Style；必要时上传一张已定稿立绘作为画风参考 |
